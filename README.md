## ⭐ Featured project

### 🍒 Cerej.ia — Corporate AI Assistant (final thesis project)
A corporate assistant that answers questions based on the company's own documents using **RAG (Retrieval-Augmented Generation)**, running a **local LLM** — no data leaves the company.

- **Stack:** C# / .NET · Blazor · PostgreSQL + pgvector · Phi-3 via Ollama
- **Highlights:** semantic search with vector embeddings, document ingestion pipeline, 100% local inference

👉 [View repository](https://github.com/EduardoPassarelli697/NOME_DO_REPO)
